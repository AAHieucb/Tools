# Postman
-> Tạo 1 workspace cho mỗi project khác nhau. 
History để xem lịch sử request ở workspace hiện tại.
Collection để nhóm các request lại. 
Có thể run collection để chạy gửi request mọi api trong collection đó nhiều lần, iterations là số lần gửi và delay là khoảng delay giữa mỗi lần => dùng test benchmark

-> Viết automation test bằng POSTMAN: vào mỗi request cần test -> tab tests -> viết code JS để test, có thể dùng snippet có sẵn bên phải để gọi nhanh -> mở console và send request để hiện test
Tests sẽ chạy sau khi nhận về response còn Pre-request Script chạy trước khi gửi request từ client -> có thể thêm code JS đó vào phần pre-request script hay tests của collection để nó chạy trước khi gửi mọi request trong collection. Đây là cách để gửi request xong lấy response về và dùng làm data để gửi request tiếp theo.
Có thể lấy từ responseBody set vào env variables của 1 request khác. Hoặc test khi chạy collection runner.

-> Tạo biến trong POSTMAN: Collection -> edit variable -> đặt tên biến và giá trị -> dùng với {{tên biến}} và save lại => biến chỉ dùng trong phạm vi collection đó
Tạo global var dùng mọi nơi: ấn vào con mắt -> add global -> save và dùng như bth
Nếu API cần chạy trên 2 môi trường khác nhau, có thể tạo global var và từng môi trường định nghĩa các env riêng, có thẻ quản lý chia env và variables.



# NewMan
Tool giúp chạy collection của Postman bằng cmd. VD có POSTMAN tạo ra 1 collection gửi cho người khác nhưng họ k dùng postman thì có thể cài nhanh newman giúp run collection via cli: npm install -g newman
C1: dùng share collection via JSON Link -> newman run <JSON Link> và kết quả hiển thị ngay trên console. Cx có thể dùng link này gửi người khác: tạo workspace -> import link này vào POSTMAN của họ để dùng => nên dùng
C2: dùng export collection -> chọn nơi lưu là có 1 file json của collection này -> tương tự dùng newman run <link tới JSON file đó> là chạy được
